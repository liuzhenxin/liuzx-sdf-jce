LiuZX SDF JCE Provider

基于 GM/T 0018-2012《密码设备应用接口规范》的 Java JCE Provider，通过 JNA 调用 SDF 密码设备（加密机 / UKey），以标准 JCE API 提供国密与主流非对称算法能力。

核心调用链

应用程序 → JCE API → Provider SPI → SDFSessionManager → JNA(SDFLibrary) → SDF 密码设备

特性

  • 符合 JCE 标准：Security.addProvider() 动态注册，通过 Signature / Cipher / KeyPairGenerator 等标准 API 调用。
  • 国密算法全面支持：SM2（签名/加密/密钥协商）、SM3、SM4（ECB/CBC/CFB/OFB）。
  • RSA：内部/外部密钥，RSA/ECB/PKCS1Padding 为标准 PKCS#1 v1.5 填充，签名与标准 JCE 验签互通。
  • 硬件密钥：SM2/RSA/SM4 内部密钥私钥永不离开设备。
  • 数盾 (Shudun) 支持：内置 SDF 动态库随 JAR 分发，开箱即用。
  • 跨平台：Linux / Windows / macOS，x86_64 / aarch64。

支持的算法

SecureRandom
SDF 硬件随机数
MessageDigest
SM3, SHA-1/224/256/384/512, MD5
Signature
SM3withSM2, SHA1/256/512/MD5withRSA, SHA256withECDSA, EdDSA, SHA1withDSA
Cipher
SM2, SM4(ECB/CBC/CFB/OFB), RSA(PKCS1/NoPadding)
KeyPairGenerator
SM2, RSA, ECDSA, EdDSA, DSA
KeyAgreement / Mac
SM2 (ECDH) · SM4MAC, HmacSM3/SHA1/SHA256/SHA512

快速开始

Security.addProvider(new LiuZXProvider());

KeyPairGenerator kpg = KeyPairGenerator.getInstance("SM2", "liuzx");
kpg.initialize(256);
KeyPair keyPair = kpg.generateKeyPair();

Signature signer = Signature.getInstance("SM3withSM2", "liuzx");
signer.initSign(keyPair.getPrivate());
signer.update("Hello, World!".getBytes());
byte[] signature = signer.sign();

构建

mvn clean package        # 构建并自动用 keystore.jks 签名 JAR
mvn install              # 安装到本地 Maven 仓库

构建产物 target/liuzx-sdf-jce-1.0.0.jar（已签名，满足 JCE Provider 安全要求）。
